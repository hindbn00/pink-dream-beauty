# Pink Dream Beauty
Site statique : `index.html` + dossier `assets/` (logo, photos). Aucun build nécessaire.

## Déploiement
1. Créer un repo GitHub et y pousser `index.html`.
2. Sur vercel.com : Add New > Project > importer le repo > Framework "Other" > Deploy.

## Modifier
En haut du `<script>` de `index.html` : `CONFIG` (téléphone, adresse, horaires) et `SERVICES` (remplacer "Sur demande" par les prix réels).
